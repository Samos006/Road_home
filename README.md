# Дорога домой

**«Дорога домой»** — веб-приложение, созданное для помощи животным из приютов Тюмени. Проект направлен на объединение информации о приютах и животных, содействие поиску новых хозяев и поддержку приютов.

##  О проекте

Проект представляет собой веб-платформу с элементами маркетплейса, где размещаются карточки животных из приютов.

Цель проекта — сделать информацию о животных, которым нужен дом, более доступной и помочь им найти любящих хозяев.

##  Основные возможности

- Просмотр карточек животных из приютов.
- Представление информации о животных, которым нужен новый дом.
- Объединение информации о приютах и животных в одном месте.

##  Технологии

- **Python** — основной язык программирования.
- **Django** — веб-фреймворк.
- **SQLite** — база данных текущей версии проекта.
- **HTML, CSS** — технологии веб-интерфейса.

##  Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Samos006/Road_home.git
cd Road_home
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

Активация в Linux / macOS:

```bash
source venv/bin/activate
```

Активация в Windows:

```bash
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Применение миграций

```bash
python manage.py migrate
```

### 5. Запуск сервера разработки

```bash
python manage.py runserver
```

После запуска открой приложение в браузере:

http://127.0.0.1:8000/
